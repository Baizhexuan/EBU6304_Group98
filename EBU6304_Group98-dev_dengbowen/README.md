```

# 2. Run  (always from the project root)
```

## Data Format

All data is stored as plain CSV files in `data\`. No database is used.

| File | Columns |
|---|---|
| `users.csv` | id, username, password, role |
| `profiles.csv` | id, userId, fullName, email, studentId, skills, gpa, cvPath |
| `jobs.csv` | id, moId, title, module, description, requiredSkills, maxHours, status |
| `applications.csv` | id, taId, jobId, status, appliedAt |

> **Note:** commas inside field values are automatically replaced with semicolons by
> `FileStorage.sanitise()` to preserve CSV integrity.

### How to Add a New Feature (example: registration)

1. Add a "Register" button to `LoginFrame.java` → open a new `RegisterFrame.java`.
2. In `RegisterFrame`, collect username/password/role, call `FileStorage.loadUsers()`, check for duplicates, append the new `User`, and call `FileStorage.saveUsers()`.
3. That's it — no schema migration needed because the CSV is plain text.

### Coding Conventions Used

- **No packages** — all source files live in `src\` with the default package for easy `javac` compilation without a build tool.
- **No external libraries** — only the Java standard library (`javax.swing`, `java.io`, `java.time`).
- **CSV delimiter** — comma (`,`); field values must not contain raw commas (use `FileStorage.sanitise()`).
- **Skill lists** — stored as semicolon-separated strings (e.g. `Java;OOP;Git`).
