BUPT TA Recruitment System JavaDoc

This API documentation covers the standalone Swing demo for the Teaching Assistant recruitment workflow. The code is organised around CSV persistence, role-specific dashboards, notification services, and explainable TA-to-job matching.

Core Areas

  • Application entry and UI: {@code Main}, {@code LoginFrame}, {@code RegisterFrame}, and the TA, MO, and Admin dashboard classes.
  • Data model: {@code User}, {@code TAProfile}, {@code Job}, {@code Application}, {@code Notification}, and {@code MatchResult}.
  • Persistence: {@code FileStorage} manages CSV-backed storage and deterministic seed data.
  • Workflow services: {@code NotificationService}, {@code MatchingService}, {@code ScoringService}, and admin recommendation helpers.
  • AI support: optional external provider classes sit behind the {@code SkillScoringProvider} interface while preserving a local rule-based fallback.
  • Regression tests: console-based test classes document expected behaviour without adding a third-party test framework.

How to Read This Documentation

Start with {@code Main} for the launch path, then review {@code FileStorage} for the CSV schema assumptions. The dashboard classes show user-facing workflows, while the service classes contain the most reusable logic.
